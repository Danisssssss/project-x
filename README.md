# Премиальное портфолио

## Самый простой просмотр
Откройте `index.html` двойным кликом. При запуске с диска он автоматически откроет `standalone.html`, который работает без Node.js и без сервера.

На главной странице появилась ссылка **«Все 40 работ»**. Она открывает отдельную страницу `works.html` с работами из архива «Для портфолио».

## Страница работ
`works.html` работает и через обычный двойной клик, и через Vite.

На странице:
- 40 работ из исходного архива;
- фильтры: цифровой дизайн, брендинг, полиграфия, среда;
- адаптивная галерея;
- полноэкранный просмотр по клику;
- переключение работ стрелками клавиатуры;
- оптимизированные WebP-версии изображений для быстрой загрузки.

Файлы галереи находятся в `assets/works/`.

## Бесконечная строка
Бегущая строка на главной теперь собрана из двух идентичных длинных групп и зациклена без разрыва или пустого участка на широких экранах.

## Полная React + Framer Motion версия
Для этой версии нужен Node.js.

### Windows
Дважды кликните `START_WINDOWS.bat`.

### Терминал
```bash
npm install
npm run dev
```
После этого откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Сборка для публикации
```bash
npm run build
npm run preview
```

## Установка UI/UX Pro Max skill
```bash
npm run skill:uiux
```

## Где менять контент
- `src/data.js` - имя, email, тексты и проекты главной страницы.
- `src/styles.css` - визуальная система главной страницы.
- `src/App.jsx` - React и Framer Motion анимации.
- `standalone.html` - автономная версия главной страницы.
- `works.html`, `works.css`, `works.js` - отдельная страница всех работ.
- `assets/works/works-data.js` - список работ и метаданные галереи.


## Последние изменения
- В избранных проектах 3 работы в одну строку на широких экранах.
- Заголовок «РАБОТЫ» на странице архива переведён с CSS-обводки на сглаженную полупрозрачную заливку.
- На мобильных экранах используется нижняя Limelight-навигация в духе компонента 21st.dev.


## 404 и бренд
- `404.html` — кастомная страница «не найдено» для статического хостинга.
- `assets/brand-logo-white.png` — белая версия логотипа для тёмного интерфейса.
- `assets/favicon.ico`, `favicon.png`, `apple-touch-icon.png` — favicon на основе логотипа.
- Основной акцент интерфейса: `#5f60ff`.
- `.htaccess` и `_redirects` добавлены для подключения `404.html` на популярных статических/Apache-хостингах.
